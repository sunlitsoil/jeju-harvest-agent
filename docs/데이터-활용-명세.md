# 데이터 활용 명세 (v0.2, 2026-11-08)

| 항목 | 내용 |
|---|---|
| 필수 데이터 | 제주데이터허브 응용서비스 「농산물 분석」(품목별 통계·품목별 도매시장 통계·월 거래량 및 가격 추이·품종별 가격 전망) 화면이 쓰는 공개 엔드포인트 |
| 원자료 | 허브 화면 표기 「데이터 출처: aT도매유통정보시스템」(전국 도매시장 경락 자료) |
| 출처 | https://jejudatahub.net (제주특별자치도·제주테크노파크 운영) |
| 호출 경로 | GET `/data-api/analysis/agricultural/item/item-list`, `item/period-date`, `item/statistics-daily`, `month/price`, `market/market-volume`, `market/price`, `market/prediction-item-list` · POST `/api/agricultural/price-prediction` |
| 활용 항목 | 기준일, 도매가격(원/kg), 거래물량(톤), 거래금액, 도매시장명·시장별 물량·평균가, 주별 실제 가격, 주별 전망가·신뢰구간(하한·상한) |
| 대상 품목 | 무(월동무 등), 당근, 양배추, 마늘, 양파의 품종 18종 |
| 수록 기간 | 2016-01-02 ∼ 2026-11-07 (2026-11-08 조회). 전망은 기준일 2026-11-07, 12주 |
| 전처리 | 거래량 가중 평균 가격, 반달 구간 집계, 연도별 중앙값, 물량 하한(구간 하루 거래량 중앙값의 25%) 미만 구간은 순위 제외, 시장 좌표 열 이름 교정(원문 latitude·longitude가 서로 바뀜), 최근 4주 물량 비중 3% 미만 시장은 가격 순위 제외, 휴장 주(실제 가격 0원) 제외, 전망 이상값 가드(마지막 실제 가격의 1/3∼3배, 그 시장 가격이 전국 최근 평균의 1/3∼3배) |
| 이용조건 | **미확인** — 허브 데이터 상세 페이지의 이용허락 표시를 확인해 채운다 |
