# 사용자 매뉴얼 (v0.3.3, 2026-11-08)

## 켜기

| 컴퓨터 | 방법 |
|---|---|
| 윈도(센터 PC) | `run_center.bat`을 두 번 누른다. 서버가 켜지고 브라우저가 열린다 |
| 맥·리눅스 | `run_center.command`를 실행한다 |
| 직접 | 폴더에서 `python3 app.py`를 실행하고 브라우저에서 http://127.0.0.1:8765 를 연다 |

Python 3.10 이상이면 되고 따로 설치할 패키지는 없다. 인터넷 연결은 필요하다(제주데이터허브 조회).

LLM을 붙이는 방법은 `.env.example`에 있다. 외부 API를 쓸 수 있으면 `AGENT_PLANNER=llm`에 큰 모델 주소를 준다. 쓸 수 없으면 아무 설정 없이 켜거나 `AGENT_PLANNER=rule`로 켠다. LLM이 없거나 응답하지 않아도 답은 나온다.

## 묻기

1. 입력칸에 평소 말투로 묻는다. 예: "월동무 지금 내도 될까?", "당근 조금 기다리면 값 오를까?", "양배추 어느 시장이 값을 잘 쳐줘?"
2. 「물어보기」를 누르거나 예시 버튼을 누른다.
3. 답 아래 「이어서 물어보기」 버튼을 누르면 같은 작물의 다른 질문(출하 시기, 시장 비교 등)으로 이어진다.

물을 수 있는 작물은 무(월동무 등)·당근·양배추·마늘·양파의 18품종이다. 제주어 "놈삐"도 무로 알아듣는다. 목록 밖 작물을 물으면 분석하지 않고 작물을 다시 묻는다. 두 작물을 한 번에 비교하거나 "3월에"처럼 기간을 정해 묻는 것은 아직 안 되며, 그때는 답 앞부분에 그렇다고 알린다.

## 답 읽기

| 화면 부분 | 내용 |
|---|---|
| 핵심 문장(노란 칸) | 아래 답에서 그대로 옮긴 1∼2문장. 전망을 물었으면 전망 결과 문장을 먼저 둔다 |
| 답(파란 칸) | 최근 7거래일 시세, 작년·5년 평균 비교, 참고 신호, 허브 전망 또는 전망을 싣지 않은 이유 |
| 그래프 | 최근 도매가, 또는 전망 시장의 주별 실제 가격과 허브 전망(점선) |
| 근거 숫자 | 답에 쓴 숫자와 그 기간·계산 방식 |
| 에이전트가 한 일 | 부른 도구, 걸린 시간, 그 도구를 부른 이유 |

참고 신호 [오름세]·[보합]·[내림세]는 최근 7거래일 가격이 직전 7거래일보다 3% 넘게 올랐는지 내렸는지만 본 것이다. 가격은 전국 도매시장 경락가(운송비 차감 전)이고 제주산 출하분만 집계했는지는 확인하지 못했다. 판매 결정은 농가가 직접 한다.

## 문제가 생기면

| 증상 | 할 일 |
|---|---|
| 브라우저에 아무것도 안 뜬다 | 검은 창(서버)이 켜져 있는지 본다. 이미 켜진 서버가 있으면 닫고 다시 켠다 |
| 「에이전트가 한 일」에 "실패"가 보이고 답이 짧다 | 허브 조회가 실패한 것이다. 인터넷 연결을 확인하고 다시 묻는다. 같은 자료를 6시간 안에 받은 적이 있으면 저장된 결과로 답한다 |
| 핵심 문장 칸이 비었다 | LLM 서버가 꺼져 있거나 느린 것이다. 답 본문은 그대로 맞다 |
