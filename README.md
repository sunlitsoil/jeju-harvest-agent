# 밭에서 묻는 시세 비서 — 제주 월동채소 출하 판단 도우미

제주데이터허브 응용서비스 「농산물 분석」(일별 도매가격·거래량·도매시장별 물량과 가격)과
「품종별 가격 전망」을 도구로 써서, 농가가 말로 물은 질문("월동무 지금 내도 될까?")에
근거 숫자와 함께 답하는 AI Agent 시제품. 2026 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 출품작(v0.3.3, 2026-11-08).

## 실행

필요한 것: Python 3.10 이상, 인터넷. 외부 패키지 설치 없음.
센터 PC에서는 `run_center.bat`(Windows) 또는 `run_center.command`(맥·리눅스)를 두 번 누르면 서버가 켜지고 브라우저가 열린다.

```bash
python3 app.py                 # 브라우저에서 http://127.0.0.1:8765
python3 cli.py "당근 요즘 시세 어때?"
python3 cli.py "월동무 언제 내면 값이 좋아?" --json
python3 -m unittest discover -s tests -v   # 인터넷 없이 저장 응답으로 재현(28개)
python3 eval/eval_planner.py               # 계획기 평가(EVAL_QS=holdout_questions.json 등으로 문항 묶음 선택)
python3 eval/forecast_coverage.py          # 허브 전망 제공 품종별 실음·제외와 이상값 배수 2·3·5 비교
```

재현 범위는 세 가지로 나뉜다. ①단위 테스트는 저장 응답만 써서 언제 돌려도 같은 결과다. ②실제 조회(`app.py`, `cli.py`)는
허브가 새 자료를 올리면 숫자가 바뀐다. ③LLM 평가는 모델·서버 버전에 따라 달라질 수 있어 당시 결과를 `eval/results/`에
모델 이름·실행 시각과 함께 남겼다.

LLM을 붙이려면 `.env.example`을 보고 환경변수를 준다. 예(Ollama):

```bash
AGENT_PLANNER=llm LLM_BASE_URL=... LLM_MODEL=<큰 모델> python3 app.py                    # 권장(외부 API 허용 시): LLM이 먼저 도구 선택, 평가 모델 gemma4 31B
AGENT_PLANNER=rule LLM_BASE_URL=http://127.0.0.1:11434/v1 LLM_MODEL=qwen3.5:4b LLM_REASONING_EFFORT=none python3 app.py   # 대체(외부 API 없음): 규칙 계획 + 4B는 핵심 문장 고르기만(선택)
```

센터 운영 PC 최소사양(i7-8700 / GTX 1060 / RAM 32GB)에서 규칙 모드는 CPU만 쓴다.

## 에이전트 흐름

1. 계획: 질문에서 작물·품종, 의도(지금 시세 / 언제 출하 / 어느 시장 / 앞으로 전망), 도매시장을 찾는다.
   `llm` 모드는 LLM이 함수 호출로 도구 4종 중 필요한 것을 고르고, `auto` 모드는 규칙이 작물을 못 찾을 때(제주어 등)만 LLM에 맡긴다.
   LLM이 목록 밖 품종·도구를 고르면 버리고 규칙으로 돌아간다.
2. 실행: 의도별로 필요한 도구만 부른다. 시즌이 아니면(최근 2주 거래 없음) 스스로 "언제" 분석을 덧붙인다.
   허브 전망은 최근 4주 물량이 많은 시장부터 최대 3곳을 물어, 값이 실제 가격·전국 평균과 동떨어진 시장은 건너뛴다.
3. 숫자는 전부 코드가 계산한다. 본문 답변은 코드가 만든 문장이고, LLM은 그 문장 가운데 질문에 가장 직접 답하는
   1∼2개의 번호만 고른다. 화면 위 「AI가 고른 핵심 문장」은 그 문장을 그대로 옮긴 것이다. 번호가 아닌 답이나 범위 밖 번호는 버린다.
4. 참고 신호 계산식: 최근 7거래일 가격이 직전 7거래일보다 +3% 이상이고 거래량 증가가 20% 미만이면 [오름세],
   -3% 이하이고 거래량이 20% 이상 늘면 [내림세], 그 밖은 [보합]. 판매 권유가 아니다.
4. 답변, 근거 숫자 표, 그래프(전망은 점선), 계획기·호출한 도구 기록, 한계를 함께 보여 준다.

`docs/데이터-활용-명세.md` 참고. 제주데이터허브(jejudatahub.net) 응용서비스 「농산물 분석」(화면 표기 원자료: aT 도매유통정보시스템)과 「품종별 가격 전망」만 쓴다.

## 한계

- 전국 도매시장 경락 가격이며 산지 가격·계약재배 가격이 아니다.
- 원 데이터가 제주산 출하분만인지, 품목별 산지 구분이 있는지는 미확인.
- 이 서비스는 가격을 예측하지 않는다. 전망은 허브가 낸 값을 인용하며, 월동무·흙당근처럼 허브 전망이 없거나 시장 가격이 동떨어진 품종은 전망을 싣지 않는다.
- 날씨·작황은 반영하지 않는다. 판매 권유가 아니라 근거 요약이다.
- v0.2 자유 요약 평가(gemma4:31b, 20문항): 채택 17건 중 1건은 숫자는 맞지만 이유를 잘못 연결했다(`eval/results/summary-llm-gemma4-31b.json`).
  그래서 v0.3에서 LLM이 문장을 새로 쓰지 않고 번호만 고르게 바꿨다(`eval/results/pick-holdout-gemma4-31b.json`, 보류 30문항: 채택 22, 폐기 1, 답 문장 1개 이하라 생략 7).
- 가격은 전국 도매시장 경락가(운송비 차감 전)다. 제주산 출하분만 따로 집계했는지는 확인하지 못했다.
