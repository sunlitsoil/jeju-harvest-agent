# 밭에서 묻는 시세 비서 — 제주 월동채소 출하 판단 도우미

제주데이터허브의 농산물 유통 분석 데이터(일별 도매가격·거래량·도매시장별 물량)를 도구로 써서,
농가가 말로 물은 질문("월동무 지금 내도 될까?")에 근거 숫자와 함께 답하는 AI Agent 시제품.
2026 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 출품용 뼈대(2026-11-02 착수).

## 실행

필요한 것: Python 3.10 이상, 인터넷. 외부 패키지 설치 없음.

```bash
python3 app.py                 # 브라우저에서 http://127.0.0.1:8765
python3 cli.py "당근 요즘 시세 어때?"
python3 cli.py "월동무 언제 내면 값이 좋아?" --json
python3 -m unittest discover -s tests -v   # 인터넷 없이 저장 응답으로 재현
```

센터 운영 PC 최소사양(i7-8700 / GTX 1060 / RAM 32GB)에서 규칙 모드는 CPU만 쓴다.

## 구조

| 파일 | 역할 |
|---|---|
| `jeju_agent/tools.py` | 제주데이터허브 공개 엔드포인트 호출 도구 5종 + 캐시 |
| `jeju_agent/analysis.py` | 최근 흐름·작년 대비·5년 같은 달 평균·시즌 반달 프로필·시장 점유율 계산, 참고 신호 |
| `jeju_agent/agent.py` | 질문 해석 → 계획 → 도구 실행 → 답변·근거표·실행 기록, 선택적 LLM 다듬기 + 숫자 가드 |
| `app.py` | 웹 화면(큰 글씨, 예시 버튼, 그래프, 근거표, 에이전트가 한 일) + `/api/ask` JSON |
| `cli.py` | 명령줄 |
| `tests/` | 오프라인 재현 테스트와 2026-11-02 수집 응답 |

## 에이전트 흐름

1. 질문에서 작물·품종과 의도(지금 시세 / 언제 출하 / 어느 시장)를 찾는다. 규칙이 못 찾으면 LLM(설정 시)이 품목 목록 안에서 고른다.
2. 의도별로 필요한 도구만 부른다. 시즌이 아니면(최근 2주 거래 없음) 스스로 "언제" 분석으로 바꾼다.
3. 숫자는 전부 코드가 계산한다. LLM은 문장만 다듬고, 근거에 없는 숫자를 쓰면 그 문장을 버린다.
4. 답변, 근거 숫자 표, 그래프, 호출한 도구 기록, 한계를 함께 보여 준다.

## 한계

- 전국 도매시장 경락 가격이며 산지 가격·계약재배 가격이 아니다.
- 원 데이터가 제주산 출하분만인지, 품목별 산지 구분이 있는지는 허브 데이터 명세 확인 전까지 미확인.
- 날씨·작황 예측은 하지 않는다. 판매 권유가 아니라 근거 요약이다.
