# 밭에서 묻는 시세 비서 — 제주 월동채소 출하 판단 도우미

제주데이터허브 응용서비스 「농산물 분석」(일별 도매가격·거래량·도매시장별 물량과 가격)과
「품종별 가격 전망」을 도구로 써서, 농가가 말로 물은 질문("월동무 지금 내도 될까?")에
근거 숫자와 함께 답하는 AI Agent 시제품. 2026 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 출품작(v0.2, 2026-11-08).

## 실행

필요한 것: Python 3.10 이상, 인터넷. 외부 패키지 설치 없음.

```bash
python3 app.py                 # 브라우저에서 http://127.0.0.1:8765
python3 cli.py "당근 요즘 시세 어때?"
python3 cli.py "월동무 언제 내면 값이 좋아?" --json
python3 -m unittest discover -s tests -v   # 인터넷 없이 저장 응답으로 재현(17개)
python3 eval/eval_planner.py               # 계획기 평가(질문 20개, 정답 품종·의도)
```

LLM을 붙이려면 `.env.example`을 보고 환경변수를 준다. 예(Ollama):

```bash
LLM_BASE_URL=http://127.0.0.1:11434/v1 LLM_MODEL=qwen3.5:4b python3 app.py              # 기본 auto 모드
AGENT_PLANNER=llm LLM_BASE_URL=... LLM_MODEL=<큰 모델> python3 app.py                    # LLM이 먼저 도구 선택
```

센터 운영 PC 최소사양(i7-8700 / GTX 1060 / RAM 32GB)에서 규칙 모드는 CPU만 쓴다.

## 에이전트 흐름

1. 계획: 질문에서 작물·품종, 의도(지금 시세 / 언제 출하 / 어느 시장 / 앞으로 전망), 도매시장을 찾는다.
   `llm` 모드는 LLM이 함수 호출로 도구 4종 중 필요한 것을 고르고, `auto` 모드는 규칙이 작물을 못 찾을 때(제주어 등)만 LLM에 맡긴다.
   LLM이 목록 밖 품종·도구를 고르면 버리고 규칙으로 돌아간다.
2. 실행: 의도별로 필요한 도구만 부른다. 시즌이 아니면(최근 2주 거래 없음) 스스로 "언제" 분석을 덧붙인다.
   허브 전망은 최근 4주 물량이 많은 시장부터 최대 3곳을 물어, 값이 실제 가격·전국 평균과 동떨어진 시장은 건너뛴다.
3. 숫자는 전부 코드가 계산한다. 본문 답변은 코드가 만든 문장이고, LLM은 위에 한 줄 요약만 붙인다.
   요약에 근거에 없는 숫자, 근거에 없는 시장 이름, 출처 없는 '전망'이 있으면 요약을 버린다.
4. 답변, 근거 숫자 표, 그래프(전망은 점선), 계획기·호출한 도구 기록, 한계를 함께 보여 준다.

`docs/데이터-활용-명세.md` 참고. 제주데이터허브(jejudatahub.net) 응용서비스 「농산물 분석」(화면 표기 원자료: aT 도매유통정보시스템)과 「품종별 가격 전망」만 쓴다.

## 한계

- 전국 도매시장 경락 가격이며 산지 가격·계약재배 가격이 아니다.
- 원 데이터가 제주산 출하분만인지, 품목별 산지 구분이 있는지는 미확인.
- 이 서비스는 가격을 예측하지 않는다. 전망은 허브가 낸 값을 인용하며, 월동무·흙당근처럼 허브 전망이 없거나 시장 가격이 동떨어진 품종은 전망을 싣지 않는다.
- 날씨·작황은 반영하지 않는다. 판매 권유가 아니라 근거 요약이다.
- AI 요약 평가(gemma4:31b, 20문항): 채택 17건 중 1건은 숫자는 맞지만 이유를 잘못 연결했다(`eval/results/summary-llm-gemma4-31b.json`). 그래서 본문은 항상 코드 문장으로 둔다.
